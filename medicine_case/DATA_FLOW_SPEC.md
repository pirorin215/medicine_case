# データフロー仕様

## 概要

このドキュメントは、スマート薬ケースシステムのデータフローと処理フローを定義します。

## システムアーキテクチャ

```
┌─────────────────┐         ┌─────────────────┐
│   マイコン       │         │  スマートフォン   │
│   (Firmware)     │         │  (Android App)   │
└─────────────────┘         └─────────────────┘
        │                              │
        │ 1. BLE接続                    │
        │──────────────────────────────>│
        │                              │
        │ 2. 時刻同期                     │
        │ <─────────────────────────────│
        │ SET:time:1779600124           │
        │                              │
        │ 3. 応答                        │
        │──────────────────────────────>│
        │ OK:time                       │
        │                              │
        │ 4. 服薬検出                    │
        │                              │
        │ 5. INTAKE通知                  │
        │──────────────────────────────>│
        │ INTAKE:1716546645             │
        │                              │
        │ 6. INTAKEクリア                │
        │ <─────────────────────────────│
        │ CLR:intake                    │
        │                              │
        │ 7. 応答                        │
        │──────────────────────────────>│
        │ OK:clr                        │
```
