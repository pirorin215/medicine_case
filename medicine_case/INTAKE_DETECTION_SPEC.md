# 服薬検出仕様

## 概要

このドキュメントは、スマート薬ケースの服薬検出ロジックと判定基準を定義します。

## 検出原理

薬ケースの傾きを6軸センサー（LSM6DS3TRC）で検知し、その角度変化を「服薬動作」として判定します。

## ハードウェア

- **センサー**: LSM6DS3TRC (6軸IMU)
  - 3軸加速度計 (X, Y, Z)
  - 3軸ジャイロスコープ (roll, pitch, yaw)
- **サンプリングレート**: 100ms間隔
- **測定範囲**: ±90度（pitch, roll）

## 検出フロー

### 状態遷移

```
IDLE（待機）→ MOVING（移動中）→ CONFIRMED（確定）→ IDLE
```

### 各状態の詳細

#### IDLE状態
- クールダウン期間中は移動検出をスキップ
- 初期位置をセット（現在のpitch, rollを記録）
- 変化量を監視（pitch, rollの変化を計算）
- 変化量 = sqrt(pitchChange² + rollChange²)
- 閾値超過でMOVING状態へ遷移

#### MOVING状態
- 安定待ち時間（500ms）を経過するのを待つ
- または強制終了時間（2000ms）で強制的に遷移
- 最大変化量を記録（各時点での最大値を保持）

#### CONFIRMED状態
- 最大変化量が閾値を超えているか確認
- 超えていればINTAKEとして記録
- IDLE状態に戻る

## 判定基準

### 角度閾値

- **デフォルト**: 70.0度
- **設定範囲**: 10.0度 ～ 180.0度
- **単位**: 度（degree）

### クールダウン時間

- **デフォルト**: 30000ms (30秒)
- **設定範囲**: 1000ms ～ 300000ms
- **目的**: 連続検出防止

### 安定待ち時間

- **固定値**: 500ms
- **強制終了**: 2000ms

## INTAKE記録

### 記録条件

1. 最大変化量が閾値を超えている
2. 安定待ち時間が経過している

### タイムスタンプ

- **時刻同期済み**: 現在のUnixタイムスタンプを記録
- **時刻未同期**: 0を記録（スマホ側で受信時刻を使用して補完）

## LEDフィードバック

### INTAKE検出時

- **パターン**: 緑色点滅（300ms ON / 200ms OFF）
- **回数**: 6回（計3秒間）
- **目的**: ユーザーへの視覚的フィードバック

### 通常時

- **色**: 接続状態・時刻同期状態で変化
- **点灯**: 常時点灯

## 通信

### INTAKE通知

- **トリガー**: INTAKE検出時
- **フォーマット**: `INTAKE:<unix_timestamp>` または `INTAKE:0`
- **宛先**: Sensor characteristic
- **即時送信**: 検出直後に送信

## エラーハンドリング

### センサエラー

- **LSM6DS3検出失敗**: 起動時のみリトライ、実行時はスキップ
- **値異常**: ログ出力して処理継続

### 判定エラー

- **NaN値**: ログ出力して処理継続
- **オーバーフロー**: ログ出力して処理継続

## 設定パラメータ

### 変更可能

| パラメータ | コマンド | デフォルト | 範囲 |
|----------|---------|----------|------|
| 角度閾値 | `SET:detection:angle:<degrees>` | 70.0度 | 10.0～90.0度 |
| クールダウン | `SET:detection:cooldown:<ms>` | 30000ms | 1000～60000ms |

### 固定値

| パラメータ | 値 | 説明 |
|----------|-----|------|
| センサー更新間隔 | 100ms | 定期的に角度を計算 |
| 安定待ち時間 | 500ms | 安定確認用 |
| 強制終了時間 | 2000ms | 安定待ちの最大時間 |
| 移動平均係数 | 0.8 | 平滑化用（alpha値） |

## パフォーマンス

### 検出精度

- **最小検出角度**: 設定閾値に依存（デフォルト70度）
- **応答時間**: 検出から通知まで最大2.5秒
- **消費電流**: センサー駆動時約5mA

### CPU負荷

- **センサー処理**: 100ms間隔で実行
- **判定処理**: 移動検出時のみ実行
- **通信処理**: イベント駆動
