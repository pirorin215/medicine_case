# BLE通信プロトコル仕様

## 概要

このドキュメントは、スマート薬ケースシステムのBLE通信プロトコルを定義します。

| UUID | プロパティ | 用途 |
|-----|-----------|------|

| `beb5483e-36e1-4688-b7f5-ea07361b26a2` | Notify | 応答通知 |

## 通信フロー

### コマンド・レスポンス通信

スマートフォンからコマンドを送信し、マイコンが応答を返すパターンです。

#### 1. 時刻同期

- **コマンド**: `SET:time:<unix_timestamp>`
- **説明**: マイコンに現在時刻を設定する
- **パラメータ**: Unixタイムスタンプ（秒単位）
- **応答**: `OK:time`
- **エラー**: `ERR:time`
- **タイミング**: BLE接続確立時に1回のみ実行（再接続時に再同期）

#### 2. 検出角度設定

- **コマンド**: `SET:detection:angle:<degrees>`
- **説明**: 服薬検出の角度閾値を設定する
- **パラメータ**: 角度（度数、浮動小数点）
- **デフォルト**: 70.0度
- **応答**: `OK:angle:<degrees>`
- **エラー**: `ERR:angle` (範囲: 10-180度)

#### 3. クールダウン設定

- **コマンド**: `SET:detection:cooldown:<ms>`
- **説明**: 連続検出を防ぐクールダウン時間を設定する
- **パラメータ**: クールダウン時間（ミリ秒）
- **デフォルト**: 30000ms (30秒)
- **応答**: `OK:cooldown:<ms>`
- **エラー**: `ERR:cooldown` (範囲: 1000-300000ms)

#### 4. INTAKE取得

- **コマンド**: `GET:intake`
- **説明**: マイコンに保存されている最新のINTAKEタイムスタンプを取得する
- **パラメータ**: なし
- **応答**:
  - `INTAKE:<unix_timestamp>`: 服薬イベントあり
  - `NONE`: 服薬イベントなし（時刻未同期または未検出）
- **タイミング**: BLE接続確立時に自動実行（再接続時にも自動実行）

#### 5. INTAKEクリア

- **コマンド**: `CLR:intake`
- **説明**: マイコンに保存されているINTAKEタイムスタンプをクリアする
- **パラメータ**: なし
- **応答**: `OK:clr`

#### 6. バージョン取得

- **コマンド**: `GET:version`
- **説明**: ファームウェアバージョンを取得する
- **パラメータ**: なし
- **応答**: `OK:version:<major>.<minor>.<patch>`

### イベント通知

マイコンからの能動的な通知です。

#### INTAKEイベント通知

- **トリガー**: マイコンが服薬を検出した場合
- **フォーマット**: `INTAKE:<unix_timestamp>` または `INTAKE:0`
- **Characteristic**: Sensor characteristic
- **即時送信**: 検出直後にBLE通知が送信される

**注意点**:
- 時刻同期前の場合: `INTAKE:0` として通知
- スマホ側でtimestamp=0の場合は受信時刻を使用して補完

### 接続時のシーケンス

1. BLE接続確立
2. サービスディスカバリー
3. 通知有効化（Response + Sensor）
4. 時刻同期（`SET:time`）
5. バージョン取得（`GET:version`）
6. INTAKE取得（`GET:intake`）

**注記**: 上記シーケンスは初回接続時だけでなく、再接続時にも自動実行されます。

### 定期通信

- 接続維持中は特になし
- 必要に応じてコマンド送信
- INTAKEイベントは即座に通知

## エラーハンドリング

### コマンド認証エラー

- 不明なコマンドを受信した場合: `ERR:unknown`

### パラメータエラー

| エラー | 応答 | 説明 |
|--------|------|------|
| 不正なパラメータ（汎用） | `ERR:param` | パラメータ形式が不正 |
| 不正なタイムスタンプ | `ERR:time` | timestampの形式が不正 |
| 不正な角度値 | `ERR:angle` | 角度が範囲外（10-180度） |
| 不正なクールダウン値 | `ERR:cooldown` | クールダウンが範囲外（1000-300000ms） |
| 不正な設定タイプ | `ERR:config` | detection config typeが不明 |

---

## 注意事項

1. **時刻同期**: 推奨ですが必須ではありません。時刻未同期時は`INTAKE:0`として記録され、スマホ側で受信時刻が使用されます。

2. **INTAKE記録**: マイコンは最新の1つのINTAKEのみ保持します。古い記録は新しいINTAKE検出で上書きされます。

3. **電源管理**: BLE通信はバッテリー消費を伴うため、頻繁な通信は避けてください。
